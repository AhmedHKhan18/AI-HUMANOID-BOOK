## Prompt

You are an expert Docusaurus architect. Your task is to add complete search functionality to my Docusaurus book built with Speckit Plus and integrate a search bar directly onto the navbar.

### Feature Summary
Implement a global search system that indexes all book content, all docs pages, all modules generated by Speckit+, and all translated content (English + Urdu).
Add a search bar to the navbar that is always visible.

### Search Requirements
- Search Provider: Use Algolia DocSearch OR local search plugin (@easyops-cn/docusaurus-search-local)
- Provide code for both, but set local search as default
- Search must index all /docs/** content, pages, headings (H1-H6), sidebars, MDX text, translated content in /i18n/ur/**
- Support auto-complete, highlighting results, result modal, keyboard shortcut "/" to focus
- RTL search compatibility for Urdu

### Navbar Search Bar Requirements
- Visible search bar (not only an icon)
- Appears on all pages
- Styled according to book's theme (green)
- Responsive on mobile (collapses into icon with modal)
- Switches text direction automatically (EN→LTR, UR→RTL)
- Placeholder text: "Search…" (English), "تلاش کریں…" (Urdu)

## Response snapshot

Implemented complete search functionality with the following components:

1. **Local Search Plugin** (`@easyops-cn/docusaurus-search-local`):
   - Configured in `docusaurus.config.js` as the default search provider
   - Indexes docs, blog, and pages
   - Supports English and Urdu languages
   - Highlights search terms on target page
   - 8 result limit with 50-character context

2. **Navbar Integration**:
   - Added search bar to navbar items with `type: 'search'`
   - Positioned on the right side before GitHub and language toggle

3. **Custom SearchBar Component** (`src/theme/SearchBar/`):
   - Wraps the local search plugin's SearchBar
   - Adds RTL support for Urdu locale
   - Implements keyboard shortcut "/" to focus search
   - Shows keyboard hint badge on desktop

4. **Comprehensive CSS Styling**:
   - Green academic theme matching the site
   - Full RTL support for Urdu with Noto Nastaliq Urdu font
   - Dark mode compatible
   - Mobile responsive with collapsible search
   - Search result highlighting

5. **i18n Translations**:
   - Updated `i18n/ur/code.json` with search-related translations
   - Created `i18n/ur/docusaurus-theme-search-local/default.json` for plugin-specific translations
   - All UI text translated to Urdu

6. **Documentation**:
   - Created `SEARCH_SETUP.md` with full configuration guide
   - Includes Algolia DocSearch alternative configuration
   - Troubleshooting tips and performance recommendations
